firefox-ctl

While this is on, the terminal can run arbitrary JavaScript in every page this add-on reaches. Leave it off unless you are debugging a page yourself.

With it off, firefox-ctl evaluate fails with EVALUATE_DISABLED and no page is touched.

getNetworkRequests --includeHeaders replaces the values of Set-Cookie, Cookie, Authorization and their kin with [redacted]. Untick this to get them raw.
